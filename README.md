# Redis Caching - MySQL vs Redis Performance (Module 4: Database)

Финальный проект 4 Модуля «Работа с БД» для курса JavaRush. Кэширование часто запрашиваемых данных из MySQL в Redis и сравнение скорости чтения. База `world` (страны, города, языки) разворачивается в Docker, данные трансформируются в DTO и переносятся в Redis, затем замеряется время выборки одинаковых записей из обеих БД.

## Функционал

- Загрузка данных из MySQL через Hibernate: выборка всех городов с подгрузкой связанных данных (страна, языки) с оптимизацией запросов.
- Трансформация данных: объекты City, Country, CountryLanguage преобразуются в плоский DTO CityCountry (только нужные поля).
- Кэширование: запись DTO в Redis (ключ - ID города, значение - JSON).
- Замер производительности: чтение набора случайных ID из Redis и из MySQL, сравнение времени выполнения.
- Логирование SQL-запросов: используется P6Spy для отслеживания запросов и параметров.
- Работа с данными в пагинации: выборка городов частями (по 500 записей) для снижения нагрузки на память.

## Стек

- Java 18
- Hibernate 5.6 (hibernate-core-jakarta)
- MySQL 8 (Docker)
- Redis (Docker, redis-stack)
- Lettuce 6.2 (Redis-клиент)
- Jackson 2.16 (JSON-сериализация)
- P6Spy 3.9 (логирование SQL)
- Maven 3

## Требования

- JDK 18+
- Maven 3.6+
- Docker
- Свободные порты 3306 (MySQL) и 6379 (Redis)
